# Auguri Elena ❤️

Pagina romantica per il tredicesimo compleanno di Elena.

## Foto

La galleria è configurata per usare questi file nella root del repository:

- `foto1.jpg` — selfie insieme
- `foto2.jpg` — ricordo all'arcade
- `foto3.jpg` — foto dell'arcade di Luigi's Mansion
- `foto4.jpg` — versione in bianco e nero del ricordo all'arcade

## Pubblicazione

Il sito è pronto per GitHub Pages. Dal repository vai in **Settings → Pages**, scegli **Deploy from a branch**, seleziona `main` e la cartella `/ (root)`, poi salva.
